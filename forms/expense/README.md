# 지출결의서 양식

- `물품구매_지출결의서_양식.docx`: 웹에서 사용하는 회사용 고정 양식. 회사용 결재란 6칸, 지급 정보, 물품명세, 관련 품의와 납품·검수·계좌·증빙 영역을 포함한다.
- `지출결의서.docx`: 이전의 간단한 지출결의서 양식. 참고용으로 보존한다.
- `지출결의서_기본양식.hwpx`, `provenance.json`: 기존 HWPX 양식과 출처 기록.

현재 웹 양식과 값 매핑은 `config/docx_gyeolui.json`에서 설정한다. 결의 검토에서 확정한 금액·지급처와 저장한 결의 정보, 증빙의 품목명세를 새 DOCX에 넣는다. 6개를 넘는 품목은 행을 추가한다. 원본 양식과 결재란의 빈 서명 칸은 유지한다. 정보가 없는 납품·검수·계좌 값은 추정하지 않는다.

다운로드할 때 DOCX 또는 PDF 하나를 선택한다. 파일은 현재 페이지의 임시 작업 공간에서만 유지한다.
